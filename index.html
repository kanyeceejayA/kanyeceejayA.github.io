Sanyu

2024 to now, AI

Uganda's AI assistant for official statistics.

Ask a question in plain language, in English or one of five Ugandan languages, and get the figure with its source, a live table or chart, or a drafted statistical brief. The language model decides what to retrieve; the statistical database decides what the value is. No figure reaches the reader unless a structured query returned it, and every figure carries its table, survey, period and geography.

  • 5,100+indicators from six official sources
  • 1,600+tables lifted from published reports, citeable by page
  • 40 mscold start, down from 30 to 60 seconds
  • 45golden-fact regression tests on every build

Node.js, SQLite, LLM tool calling, RAG, MCP endpoints, Python pipelines, Nginx and pm2. Built in-house at UBOS with Sunbird AI on the language side.

statistics.ubos.org/sanyu

Tools for census and survey teams

csync, a CSPro synchronisation suite

2026, open source

Sync any CSPro survey between a CSWeb server and your own code.

Most census and survey fieldwork in the region runs on CSPro: tablets collect cases and sync them through a CSWeb server. Getting those cases in and out from your own code is the hard part. csync reads a survey's dictionary and does the rest. Pull cases into a plain SQLite store, add, edit or remove them as ordinary Python dictionaries, and push them back so they reach the tablets, with the vector clocks CSEntry expects.

It works for any dictionary, from assignments and staff lists to a full household questionnaire, and speaks both CSWeb 8.0 and 8.1. It comes as a Python library, a command line, a one-page web front end, and readers and writers for CSPro's own data files.

  • AnyCSPro dictionary, with no field names hard-coded
  • 8.0 and 8.1CSWeb versions it speaks
  • 0third-party packages the core library needs

Python's standard library, SQLite and the CSWeb REST API, with an optional Flask page.

csync on GitHub

CSPro toolkit, a skill for AI assistants

2026, AI

Teaches Claude and other AI assistants to read, edit and check CSPro survey apps.

A CSPro application is a set of files that must stay in step: the dictionary, the logic, the forms and the run files. CSPro can't compile an entry app from the command line, so an AI assistant editing one is working blind. This skill gives it the map.

It explains what each file is for and how a change in the dictionary ripples into the logic and run files. It adds a linter that pre-checks logic edits before anyone opens CSPro, walks through building and releasing a deployment package, and shows how to ask a CSWeb server for its dictionaries, case counts, sync history and cases. It is packaged as an Agent Skill, the SKILL.md format that Claude and other assistants can load.

Markdown instructions, Python helper scripts, and a reference for the CSWeb API.

The 4th Industrial Revolution Taskforce

April 2019 to January 2021

In April 2019 President Museveni set up a 21-member expert taskforce, chaired by former ICT minister John Nasasira, to study the technologies of the fourth industrial revolution and advise government on how Uganda should adopt them.

I joined from the Ministry of ICT's Government Citizen Interaction Centre, a few months after finishing university, and met the President with the rest of the team when he launched it.

Over the next eighteen months we studied how other countries were preparing and wrote the report that became Uganda's national 4IR strategy: skills, infrastructure, research, cyber security and data protection, aimed at making Uganda a 4IR hub by 2040. The draft went public in October 2020, and the final report was handed to the Prime Minister in December 2022.

Read the appointment on the Ministry of ICT site

Along the way I built my classmates a small offline revision site, with flashcards, mock exams, a Kiswahili songbook and a shared leaderboard.
