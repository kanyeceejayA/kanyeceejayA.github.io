Five rules for AI over official statistics

4 August 2026

Generative systems are arriving in statistical dissemination across the continent this year, often procured quickly and judged more on how fluent they sound than on whether the numbers are right. A model that produces a confident, wrong district population hands the reputational bill to the office that published it. Official statistics carry value only because the public accepts the figure.

So before Sanyu goes out as a public service of the Bureau, we wrote down the conditions we had to meet to feel safe releasing it. Five clauses, each one drawn from something the build itself forced on us. They're short enough to check.

1. Figures originate in the statistical system

The model selects what to retrieve; the database supplies the value. A number reaches the user only when a structured query returned it. This is the whole architecture in one sentence. The language model never generates a figure, it emits a typed function call, and the verified result is placed into the answer verbatim.

2. Every figure carries its source

Source table, survey or census, reference period and geography travel with the value, in a form the user can follow back to the publication. Charts render from the same verified values as the surrounding text, so a picture can't disagree with its caption.

3. The system declines outside its data

Where a question falls beyond published statistics, the correct response says so plainly. Silence about a limit counts as a defect. This one was harder to build than it sounds, because a fluent model would much rather answer.

4. Evaluation is published before launch

A named benchmark with ground truth, plus a regression suite that asserts exact published figures, runs automatically on every build. Ours has 45 deterministic tests, including a set of golden facts that must match the printed census tables to the digit. The results are public.

5. A statistician signs

Generated narrative passes a named human reviewer before publication. The machine drafts; the office remains the author.

The code demonstrates that the conditions are achievable, because the system standing beside it meets them.

None of these rules is about a particular vendor or model. They're conditions any statistics office could adopt this year, and we'd like other offices to argue with them, adapt them, and tell us what we missed. The technical details of how Sanyu meets them are on the work page.
